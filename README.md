## Projects
# Sales Data Analysis: Data Cleaning & Exploratory Data Analysis (EDA)

## 1. Project Overview

This project uses Python to analyze sample sales data, calculate revenue, compare product performance, and identify useful business insights.

The goal is to practice fundamental Data Analyst skills using a small dataset.

## 2. Problem Statement

A business wants to understand its sales performance by answering these questions:

- What is the total revenue?
- How many units were sold?
- Which product generated the highest revenue?
- Which category contributed the most revenue?

## 3. Tools and Technologies

- **Python** — programming and analysis
- **Pandas** — data manipulation and analysis
- **Matplotlib** — data visualization
- **NumPy** — imported in the original script but not yet used

## 4. Dataset Description

The project uses a manually created sample dataset with 10 sales records.

| Column | Description |
|---|---|
| Product | Name of the product sold |
| Category | Product category |
| Quantity | Number of units sold in a record |
| Unit_Price | Price per unit in rupees |
| Revenue | Quantity multiplied by unit price |

Revenue is calculated using:

`Revenue = Quantity × Unit_Price`

## 5. Project Workflow

1. Created a sample sales dataset using Python.
2. Converted the data into a Pandas DataFrame.
3. Inspected the dataset and its column types.
4. Removed duplicate rows and rows with missing values.
5. Calculated revenue for each sales record.
6. Grouped and summarized revenue by product and category.
7. Sorted product revenue to identify the highest-revenue product.
8. Created and saved a bar chart using Matplotlib.

## 6. Key Results

| Metric | Result |
|---|---:|
| Total Revenue | ₹5,87,000 |
| Total Quantity Sold | 33 units |
| Top Product by Revenue | Laptop |
| Laptop Revenue | ₹3,00,000 |
| Top Category | Electronics |
| Electronics Revenue | ₹5,65,000 |

## 7. Business Insights

- Laptops generated the highest revenue among the products in the sample dataset.
- Electronics contributed the most revenue across the two categories.
- The business could investigate product demand, profit margins, and inventory levels before making decisions.

**Note:** These findings come from a small sample dataset and should not be treated as conclusions about a real business.

## 8. Project Files

- `sales_analysis.py` — Python code for data inspection, cleaning, revenue calculations, analysis, and chart generation.

The script prints sales summaries and displays the product revenue chart. It also saves the chart as `revenue_by_product.png`.
